# Dépendances de PRODUCTION pour le dashboard SpyBusiness (Render, plan gratuit 512 Mo).
# Volontairement distinct du requirements.txt racine (qui couvre en plus tout le pipeline
# d'extraction PDF→BD : docling, paddleocr, torch-vision, streamlit... inutile ici et beaucoup
# trop lourd pour l'image servie). Ce fichier ne liste que ce que server.py / dash_app
# importent réellement à l'exécution.
#
# Volontairement ABSENTS : torch / sentence-transformers / langchain-* (chat IA à recherche
# sémantique locale). server.py détecte leur absence proprement (_RAG_OK=False) et désactive
# juste le chat avec un message clair — le reste du dashboard (Santé financière, Conditions
# bancaires, Stratégie) n'en dépend pas et fonctionne normalement.
#
# POIDS MESURÉ (2026-08-07), pour que le choix soit documenté et non supposé :
#     torch                                        509 Mo
#     transformers, scipy, sklearn, numpy…          292 Mo
#     modèle paraphrase-multilingual-mpnet-base-v2 1 126 Mo
#     ────────────────────────────────────────────────────
#     total pour la recherche sémantique          ≈ 1,9 Go
#
# Le cache Hugging Face de la machine de développement pèse 7,4 Go, mais le chat n'utilise
# qu'UN seul de ces modèles : le reste (docling, bart-large-mnli, modèles de sentiment) sert
# au pipeline d'extraction des PDF, qui n'a pas à être déployé.
#
# LE CHAT EST NÉANMOINS DISPONIBLE (2026-08-09) — SANS AUCUN POIDS LOCAL.
# La question posée est vectorisée par l'API d'inférence de Hugging Face, qui exécute LE MÊME
# modèle ; les vecteurs des 31 985 documents, eux, sont déjà en base. On ne transporte donc
# qu'une phrase, et le gigaoctet et demi de torch reste sur le poste de développement.
# Voir RAG/retriever.py, PGVectorStore._embed_distant. Requiert HF_TOKEN (droit d'inférence).
#
# MESURÉ AVANT D'Y CROIRE, car tout repose là-dessus : si l'API agrégeait ou normalisait
# autrement, elle rendrait des vecteurs incomparables à ceux stockés, et le chat répondrait à
# côté SANS jamais signaler d'erreur. Sur quatre questions réelles, vecteur local contre
# vecteur distant :
#     similarité cosinus              1,000000
#     écart maximal par coordonnée    1,1 × 10⁻⁷   (bruit de virgule flottante)
# Recherche de bout en bout vérifiée : « tarif de la carte VISA PLATINUM » rend en premier
# « Première carte (VISA PLATINUM) » à 175 000 FCFA. C'est cette mesure qu'il faut refaire en
# premier si le chat se met un jour à répondre de travers.
#
# ATTENTION : l'adresse historique « api-inference.huggingface.co » ne résout MÊME PLUS en DNS.
# Hugging Face l'a remplacée par router.huggingface.co. Le code essaie les formes connues dans
# l'ordre plutôt que d'en figer une seule.
#
# Piste de repli si l'API venait à fermer ou à imposer un quota gênant : exporter le même
# modèle en ONNX et l'exécuter avec onnxruntime (≈ 300 Mo quantifié int8, contre 1,9 Go).
# Mêmes poids, donc mêmes vecteurs — mais du travail, et à valider par la même mesure.
#
# Écartée : un modèle plus petit (MiniLM, 480 Mo) produit des vecteurs à 384 dimensions,
# incompatibles avec ceux stockés — il faudrait ré-encoder les 31 985 documents.
